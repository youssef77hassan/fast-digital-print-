# Fast Digital Print

A premium, bilingual (Arabic / English) front-end website for a printing and branding studio, built with React, TypeScript, Vite and Tailwind CSS. Inquiries go straight to WhatsApp.

**Front-end only:** there is no backend and no API keys. The order-tracking popup is a UI demo using sample data (labelled DEMO in the UI).

## Features
- Light / dark theme and Arabic (RTL) / English language switch
- Glass navbar, video hero, products, testimonials, contact form and map
- Contact form compiles the inquiry into a WhatsApp message
- Responsive layout

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
The output in `dist/` can be hosted on GitHub Pages, Vercel or Netlify.

## Stack
React 19 · TypeScript · Vite · Tailwind CSS 4 · Motion · Lucide

## Images
All images live in `public/images/` (`products/`, `portfolio/`, `posters/`). The current files are generated placeholders: replace any of them with your own photo using the **same file name** and the site updates with no code changes.

## Deploy
Pushing to `main` deploys automatically to GitHub Pages via GitHub Actions (enable it in *Settings → Pages → Source: GitHub Actions*).
